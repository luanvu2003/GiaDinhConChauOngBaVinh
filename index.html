Cấu hình GitHub Token

Để website tự động tải ảnh và lưu trữ lên GitHub Pages, bạn cần cung cấp Personal Access Token (PAT) có quyền Contents: Read and Write hoặc repo. Token này chỉ lưu trên trình duyệt của bạn và không chia sẻ cho người ngoài.

Trạng thái: Chưa cấu hình

Cách lấy Token (chỉ mất 1 phút):

  1. Truy cập GitHub Tokens (Classic) hoặc Fine-grained tokens.
  2. Tạo token mới, tích chọn quyền repo (hoặc Repository permissions: Contents -> Read & Write).
  3. Sao chép mã token và dán vào ô bên trên, sau đó bấm Lưu Token.
